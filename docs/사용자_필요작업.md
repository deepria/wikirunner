# WikiRunner 사용자 필요 작업

비밀번호나 비밀키는 채팅에 공유하지 않는다.

전체 구현·검증·잔여 작업 상태는 [진행 현황](진행현황.md)에서 확인할 수 있다.

## 완료된 작업

- WikiRunner Supabase 프로젝트 생성 및 저장소 연결
- Anonymous Sign-Ins 활성화와 실제 세션 생성 확인
- migration 적용 및 원격 DB lint 통과
- Publishable key 기반 웹·확장 로컬 환경 설정
- `PAIRING_CODE_SECRET` 생성 및 Edge Function secret 등록
- `game-api` Edge Function 배포
- 방 생성부터 완주·순위까지 원격 통합 검증
- Chrome에 개발용 확장 프로그램 수동 로드

## 현재 사용자가 해줄 작업

### Chrome 확장 프로그램 실동작 확인

1. Chrome에서 `http://localhost:3000`을 연다.
2. 새 방을 만들고 시작 문서는 `대한민국`, 목표 문서는 `서울특별시`로 저장한다.
3. **페어링 코드 발급**을 누르고 WikiRunner 확장 팝업에 코드를 입력한다.
4. 웹에서 **준비 완료**, **10초 카운트다운 시작**을 차례로 누른다.
5. 나무위키 게임 탭이 자동으로 열리고 우측 상단에 WikiRunner 오버레이가 보이는지 확인한다.
6. `서울특별시` 본문 링크를 눌러 완주 상태와 웹 순위를 확인한다.

문제가 생기면 어느 단계에서 어떤 문구가 표시됐는지만 알려준다. 비밀키나 브라우저 저장
데이터는 보내지 않는다.

## 공개 배포 전 필요한 작업

- CAPTCHA 또는 Cloudflare Turnstile 연결
- 실제 웹 배포 도메인으로 Supabase Site URL과 Redirect URL 변경
- 개발 테스트로 생성된 익명 사용자와 방 데이터 정리
- Chrome Web Store 배포 계정과 개인정보 처리 안내 준비

## 선택 작업: 로컬 Supabase 실행

원격 Supabase 통합 검증은 완료됐다. 별도의 로컬 DB 통합 테스트가 필요하다면 다음 중
하나를 설치할 수 있다.

- Docker Desktop
- OrbStack
- 기타 Docker 호환 컨테이너 런타임

원격 개발 프로젝트를 사용하고 있으므로 현재는 설치하지 않아도 된다.
