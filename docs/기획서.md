# WikiRunner 제품 명세

이 문서는 현재 제품 범위와 게임 규칙을 설명한다. 구현 상태와 남은 작업은
[진행 현황](진행현황.md), 기술 구조는 [아키텍처](아키텍처.md)를 기준으로 한다.

## 1. 제품 개요

WikiRunner는 참가자가 나무위키 문서의 본문 내부 링크만 따라 시작 문서에서 목표 문서까지
이동하는 친선 멀티플레이 스피드런 게임이다.

- 웹 앱은 방 생성·참가, 경기 설정, 준비 상태와 리더보드를 제공한다.
- Chrome 확장 프로그램은 웹과 플레이어를 연결하고, 경기 탭의 이동을 기록하며 게임 규칙을
  안내한다.
- 서버는 시작 시각, 이벤트 수락, 완주 시간과 순위를 결정한다.

### 목표

- 친구들이 방 코드만으로 빠르게 모여 같은 시각에 경기를 시작한다.
- 참가자의 정상 링크 이동과 완주 기록을 일관되게 남긴다.
- 경기 종료 후 참가자별 이동 경로와 경고 여부를 확인한다.

### 현재 범위 밖

- 상금·공식 대회 수준의 부정행위 방지
- 나무위키 전체 문서 그래프 수집과 최단 경로 계산
- 로그인 계정, 영구 전적, 친구, 관전, 공개 방
- 모바일 브라우저 지원

## 2. 사용자와 경기 흐름

### 역할

- **방장**: 방 생성, 경기 설정, 카운트다운 시작, 경기 종료와 다음 경기 준비. 대기 중인
  다른 참가자를 강퇴할 수 있다.
- **참가자**: 방 참가, 확장 프로그램 연결, 준비, 경기 진행과 포기. 대기 중에는 방을 나갈 수 있다.

### 기본 흐름

1. 방장이 웹에서 방을 만들고 6자리 방 코드를 공유한다.
2. 참가자는 코드와 닉네임으로 방에 들어온다.
3. 각 참가자는 웹의 **확장 프로그램 연결**을 눌러 같은 브라우저 프로필의 확장 프로그램과 자동 연결한다.
4. 방장이 시작·목표 문서를 직접 입력하거나 랜덤 경로를 추첨한다.
5. 모든 참가자가 확장을 연결하고 준비하면 방장이 10초 카운트다운을 시작한다.
6. 확장 프로그램이 참가자별 전용 경기 탭에서 시작 문서를 연다.
7. 참가자는 본문 내부 링크를 따라 목표 문서로 이동한다.
8. 목표 도달, 포기 또는 방장 종료 뒤 웹에서 결과와 이동 경로를 확인한다.
9. 방장은 같은 방을 다음 경기 준비 상태로 되돌릴 수 있다.

### 랜덤 경로

랜덤 경로는 방장과 연결된 확장 프로그램이 나무위키의 랜덤 문서에서 시작해 제한 깊이
랜덤 워크로 생성한다. 난이도별 생성 깊이는 쉬움 3~4, 보통 5~6, 어려움 7~8이다.

- 한 경기 준비당 최대 10회 추첨할 수 있다.
- 확장 프로그램이 확인한 경로의 처음과 끝을 시작·목표 문서로 사용한다.
- 서버는 제출된 경로와 설정을 경기 생성 시점에 스냅샷으로 고정한다.
- 생성 경로는 경기 중 숨기고, 경기가 끝나거나 취소된 뒤 참가자에게 공개한다.
- 현재 서버 환경에서는 나무위키 자동 요청이 HTTP 403으로 차단되어 브라우저에서 생성한다.
  이 때문에 방장은 생성 경로를 알 수 있으며, 공개 경쟁용 공정성은 보장하지 않는다.

## 3. 게임 규칙

| 항목 | 규칙 |
| --- | --- |
| 시작 | 서버가 정한 `scheduledAt`에 참가자 전원이 시작한다. |
| 이동 | 전용 경기 탭의 현재 문서 본문에 있는 나무위키 문서 링크를 사용한다. |
| 완주 | 승인된 이동으로 목표 문서의 정규화된 문서 키에 도달하면 자동 기록한다. |
| 순위 | 방장이 대기 중 정한 기준을 게임 시작 시 고정한다. 시간순은 완주 시간→이동 횟수, 횟수순은 이동 횟수→완주 시간 순이며, 이후 서버 완주 시각과 run ID로 안정적으로 정렬한다. |
| 뒤로/앞으로 | 경로에는 기록하되 이동 횟수에는 포함하지 않는다. |
| 새로고침 | 허용하며 이동 횟수에는 포함하지 않는다. |
| 포기 | 확장 프로그램 팝업에서 현재 경기를 포기할 수 있다. |
| 금지 조작 | 검색·랜덤·분류·본문 밖 링크와 관련 단축키는 차단·안내한다. 주소 직접 입력과 새 탭 우회처럼 실제 탐색이 발생하면 경고로 기록한다. |

허용 문서는 `https://namu.wiki/w/...` 형식의 일반 문서다. 파일·분류와 편집·토론·역사 등
게임 문서가 아닌 경로, 외부 링크와 페이지 내 앵커는 정상 이동으로 인정하지 않는다.

## 4. 공정 플레이 정책

WikiRunner는 정상적인 친선 경기를 돕는 도구이며 브라우저 전체를 통제하는 감독 도구가 아니다.

- 경기 탭에서 검색·랜덤 문서와 관련된 헤더, 사이드바, 클릭과 단축키를 차단한다.
- 차단된 검색·랜덤·분류·본문 밖 링크 클릭은 화면 안내만 표시한다. 별도 나무위키 탭 사용과
  직접 이동처럼 실제 탐색이 발생한 경우만 서버 경고로 기록한다.
- 링크 이동은 클릭 의도, 실제 도착 문서, 연속 번호와 해시 체인을 함께 검증한다.
- 자동 실격은 적용하지 않는다.
- 주소창, 개발자 도구, 다른 브라우저 프로필, 확장 프로그램 비활성화까지 완전히 차단할 수 없다.
- 검색어, 전체 DOM, 전체 브라우징 기록은 수집하지 않는다.

세부 결정은 [ADR-005](adr/ADR-005-warning-based-fairness.md)와
[ADR-006](adr/ADR-006-fair-play-ui-blocking.md)을 따른다.

## 5. 기능 범위

### 현재 MVP

- 익명 인증과 6자리 방 코드 기반 방 생성·참가
- 방 안에서 중복되지 않는 닉네임과 2~12명 정원
- 웹-확장 1분 만료 일회용 nonce 자동 페어링과 5분 만료 수동 코드 예비 연결, 연결 해제와 재연결
- 직접 문서 설정과 난이도별 랜덤 경로 생성
- 준비 확인, 서버 기준 10초 카운트다운과 전용 탭 시작
- 대기 중 방 나가기·방장 강퇴, 정원 즉시 반환
- 시간순·횟수순 랭킹 기준 설정과 게임별 스냅샷 고정
- 링크 이동·뒤로/앞으로·새로고침·직접 이동 기록
- 목표 도달, 완주 시간, 이동 횟수와 순위 계산
- 참가자별 경로 조회, 경기 포기, 방장 종료와 다음 경기
- 검색·랜덤 UI 차단, 직접 이동·새 탭 경고
- 전송 대기열과 스냅샷 기반 확장 프로그램 복구

### 후속 후보

- 실제 플레이 결과를 이용한 랜덤 경로 난이도 보정
- 제한 BFS 또는 짧은 TTL 그래프 캐시
- 경고 검토와 방장 실격 판정 UI
- 계정·전적·일일 챌린지·관전·공개 방
- 운영 지표, 데이터 만료와 사용자 삭제 정책 자동화

후속 후보는 확정 일정이 아니며 현재 MVP의 동작을 설명하지 않는다.

## 6. 성공 및 출시 기준

- 실제 Chrome에서 여러 참가자가 페어링·준비·동시 시작·완주할 수 있다.
- 정상 내부 링크 이동과 이동 횟수가 웹 리더보드에 일관되게 반영된다.
- 완주·포기·경기 종료 뒤 확장 프로그램이 다음 경기 대기 상태로 복구된다.
- 차단된 조작은 안내만 표시되고, 실제 우회 탐색만 경고로 표시된다.
- 공개 전 익명 로그인 남용 방지, 운영 URL, 개인정보·권한 고지와 배포 점검을 마친다.

## 7. 운영 원칙

- WikiRunner가 나무위키와 제휴하거나 공식 지원을 받는 서비스가 아님을 표시한다.
- 나무위키에 전체 크롤링이나 대규모 자동 요청을 보내지 않는다.
- 비밀값, JWT, 페어링 코드와 서비스 역할 키를 클라이언트나 로그에 노출하지 않는다.
- 상금·공식 경쟁전 도입 전에는 별도의 공정성, 개인정보와 서비스 정책 검토를 거친다.
