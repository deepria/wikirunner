# ADR-003: 서버 수신 시각 기반 완주 기록

- 상태: 승인
- 날짜: 2026-07-27

## 배경

클라이언트 시계는 틀리거나 조작될 수 있다. 네트워크 지연을 완전히 제거하면서 동시에
신뢰할 수 있는 공식 시간을 얻기는 어렵다.

## 결정

- 공식 시작 시각은 서버 트랜잭션이 만든 `scheduled_at`으로 고정한다.
- 승인된 목표 도달 이벤트를 서버가 처음 받은 시각을 `finished_at`으로 기록한다.
- `duration_ms`는 서버에서 `finished_at - scheduled_at`으로 계산한다.
- 클라이언트 관찰 시각은 진단용으로만 저장하며 기록 계산에 사용하지 않는다.

## 결과

클라이언트 시계 조작이 공식 기록에 영향을 주지 않는다. 네트워크 지연이 기록에 포함된다는
점을 사용자에게 알리고, 리전과 처리 지연 지표를 운영해야 한다.
