# ADR-006: 공정 플레이 UI 차단과 서버 검증의 단계적 도입

- 상태: 구현 완료, 실제 Chrome 수동 점검 필요
- 날짜: 2026-07-28

## 배경

현재 MVP는 본문 링크 클릭과 실제 문서 이동을 연결해 기록하고, 직접 이동은 경고로 남긴다.
참가자가 나무위키 검색, 랜덤 문서, 실시간 검색어 또는 해당 단축키를 이용하면 본문 내부 링크만
따른다는 게임 규칙을 우회할 수 있다.

일반 Chrome Manifest V3 확장 프로그램은 페이지 안의 UI를 숨기거나 클릭·키 입력을 막을 수 있지만,
주소창 직접 입력, 새 탭, 개발자 도구, 다른 브라우저 프로필, 확장 프로그램 비활성화까지 완전히
차단할 수는 없다.

## 구현된 설계

공정 플레이 강화가 필요해지면 아래 순서로 도입한다.

1. **경기 탭 UI 차단**: Content Script가 상단 헤더, 검색창, 랜덤 문서, 우측 사이드바의 실시간 랭킹·검색어 영역을 숨기고 해당
   클릭과 알려진 단축키를 차단한다.
2. **알려진 URL 차단**: 검색·랜덤 문서의 확인된 URL 패턴은 Manifest V3의
   `declarativeNetRequest` 동적 규칙으로 경기 중에만 차단하고, 경기 종료 시 제거한다.
3. **서버 권위 유지**: 주소창, 새 탭 등 UI 차단 밖의 이동은 정상 링크로 인정하지 않고 위반
   근거로 기록한다. 반복 위반의 자동 실격 여부는 별도 게임 규칙 결정 후 도입한다.
4. **투명한 안내**: 차단된 조작에는 이유를 표시하고, 방과 리더보드에는 경고 여부만 공개한다.
   검색어 원문, 전체 DOM, 불필요한 브라우징 기록은 수집하지 않는다.

## 결정

- 경고 기반 판정 정책은 [ADR-005](ADR-005-warning-based-fairness.md)를 유지한다.
- 검색·랜덤 문서 UI 차단 또는 단축키 차단 시 `search_attempt` 경고를 남긴다.
- 경기 탭 밖에서 나무위키 문서를 여는 이동은 `new_tab` 경고를 남긴다.
- 자동 실격은 도입하지 않는다. 방과 리더보드에는 기존처럼 경고 여부만 공개한다.
- 나무위키의 DOM·URL은 외부 계약이므로, 확장 프로그램 버전 업데이트마다 실제 Chrome에서 다시 점검한다.

## 결과

친선 게임 단계에서는 과도한 권한과 유지보수 비용을 피한다. 경쟁성·보상성이 높아지는 시점에는
UI 차단만으로 완전한 부정행위 방지가 되지 않는다는 한계를 명확히 고지하고, 서버 판정과 운영
정책을 함께 강화한다.
