# ADR-001: 익명 인증과 웹-확장 페어링

- 상태: 승인
- 날짜: 2026-07-27

## 배경

웹과 확장 프로그램은 서로 다른 실행 환경이며, 방 코드만으로 플레이어를 식별하면 다른
참가자를 사칭할 수 있다. MVP에서는 이메일 같은 개인정보 없이 사용자별 권한을 구분해야
한다.

## 결정

- 웹과 확장은 각각 Supabase 익명 사용자로 인증한다.
- 웹에서 참가한 플레이어가 5분 만료 일회용 페어링 코드를 발급한다.
- 서버는 코드 원문 대신 해시만 저장하고, 성공 또는 5회 실패 시 코드를 폐기한다.
- 페어링 성공 시 확장 사용자를 해당 플레이어의 `extension` identity로 연결한다.
- 방 초대 코드는 방 검색에만 사용하고 인증 수단으로 취급하지 않는다.

## 결과

개인정보 수집 없이 웹과 확장을 안전하게 연결할 수 있다. 익명 계정과 페어링 시도에 대한
CAPTCHA, rate limit, 만료 계정 정리가 필요하다.
