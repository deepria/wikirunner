# ADR-005: 경고 기반 MVP 공정성 모델

- 상태: 승인, 방장 판정 UI는 후속
- 날짜: 2026-07-27

## 배경

Chrome 확장 프로그램만으로 주소창, 새 탭, 개발자 도구 조작을 완전히 차단할 수 없다.
친선 게임 MVP에서 완전한 치팅 방지는 범위와 비용에 맞지 않는다.

## 결정

- 정상 이동은 클릭 의도, 실제 탐색, 연속 sequence, 문서 연결, hash chain으로 검증한다.
- 직접 이동·새 탭·잘못된 탭·외부 링크 등은 위반 경고와 근거를 남긴다.
- 경고는 자동 실격으로 처리하지 않는다.
- 현재는 경고를 리더보드에 표시하고 자동 실격하지 않는다.
- 방장이 경고를 승인하거나 실격 처리하는 UI/API는 후속 기능으로 둔다. 이를 위한
  `result_decisions` append-only 스키마는 마련되어 있다.
- 원본 URL, 검색어, 전체 DOM 같은 불필요한 민감 데이터는 저장하지 않는다.

## 결과

친선 플레이에 필요한 투명성을 제공하면서 과도한 권한과 수집을 피한다. 판정 기능이 추가되기
전까지 경고는 참고 정보이며 최종 순위를 자동으로 바꾸지 않는다. 서비스 화면에 부정행위 방지
한계를 명시해야 하며, 상금 경기는 별도 공정성 설계가 필요하다.
