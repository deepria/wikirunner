# WikiRunner 구현 진행 현황

최종 갱신: 2026-07-28 (Asia/Seoul)

## 현재 상태

P0 MVP의 핵심 흐름은 구현되어 원격 Supabase 환경에서 검증했습니다. 방 생성부터 확장 프로그램 페어링, 게임 시작, 나무위키 페이지 이동 기록, 순위 산출, 경기 포기와 종료 후 초기화까지 동작합니다.

아직 운영 공개 전 단계이며, 실제 Chrome 환경에서 최신 확장 프로그램 동작을 한 번 더 확인하고 운영 보안·배포 항목을 마무리해야 합니다.

## 원격 환경 반영·검증

- Supabase 프로젝트 `hvwwrcfmxcsrisiadvfc`에 스키마 마이그레이션 8건을 적용했습니다.
- `game-api` Edge Function을 배포했습니다.
- 익명 로그인이 가능한 것을 확인했습니다.
- 방 생성 → 설정 → 페어링 → 준비 → 카운트다운 → 경기 시작 → 이동 기록 → 목표 도착 흐름을 확인했습니다.
- 경기 포기 API를 원격 환경에서 검증했습니다. 단독 참가자가 포기하면 실행은 `abandoned`, 경기는 `cancelled`, 방은 `finished`로 처리됩니다.
- 단위 테스트 31개, 린트, 타입 검사, 웹·확장 프로그램 빌드, 원격 DB 린트를 통과했습니다.

## 현재 확인이 필요한 항목

Chrome 확장 프로그램을 최신 버전(0.1.4)으로 다시 로드한 뒤 아래 항목을 확인하면 됩니다.

1. 경기 중 팝업의 `이번 경기 포기`를 눌렀을 때 확인창 뒤 대기 상태로 돌아오는지
2. 목표 문서에 도착해 완주한 뒤에도 확장 프로그램이 다음 경기 대기 상태로 돌아오는지
3. 이동할 때마다 팝업과 방 리더보드의 이동 횟수가 유지되는지

자세한 사용자 작업과 로컬 실행 방법은 [사용자 필요 작업](사용자_필요작업.md)을 참고합니다.

## 남은 작업

### MVP 마무리

- 실제 Chrome에서 여러 참가자가 동시에 접속하는 최종 수동 시나리오 점검

### 공개 배포 전

- 익명 로그인 악용 방지 정책(CAPTCHA 또는 Turnstile 등) 적용
- 운영 도메인의 인증 리디렉션·허용 URL 설정
- 개발 중 생성된 익명 사용자와 테스트 방 데이터 정리
- CI와 배포 절차 정리, Chrome Web Store 배포 준비

## 운영 메모

- Supabase Auth 설정은 반영되어 익명 로그인이 정상 동작합니다. 설정 반영 과정에서 Storage 관련 구성 경고가 있었으나, 현재 앱 기능과 DB 스키마 검사에는 문제가 없습니다. 공개 배포 전에 Storage 설정을 별도로 점검합니다.
- 비밀값은 저장소에 넣지 않습니다. 프로젝트 URL과 공개 키는 각 앱의 `.env.local`에만 두고, 페어링 서명 비밀값은 Supabase 원격 시크릿으로 관리합니다.

## 갱신 기준

기능 구현, 원격 반영, 사용자 확인 결과 또는 배포 준비 상태가 바뀔 때 이 문서를 함께 갱신합니다.
