## 상세 설명

WikiRunner는 친구들과 함께 나무위키 문서 링크만 따라 달리는 실시간 스피드런 게임입니다.

웹에서 방을 만들거나 초대 코드로 참가한 뒤, 페어링 코드로 확장 프로그램을 연결하세요. 모두 준비되면 같은 시작 문서에서 동시에 출발합니다. 경기용 나무위키 탭에서 본문 내부 링크만 따라 목표 문서에 먼저 도착하면 됩니다.

주요 기능

- 방 코드로 친구를 초대해 2~12명이 함께 플레이
- 시작·목표 문서를 직접 정하거나 난이도별 랜덤 경로 생성
- 동시 시작 카운트다운과 전용 경기 탭 자동 열기
- 이동 횟수와 완주 시간을 기록해 실시간 리더보드 표시
- 경기 중 검색, 랜덤 문서, 주소 직접 입력 같은 우회 시도를 차단하거나 경고로 기록

이 확장 프로그램은 WikiRunner 웹 앱과 연결해 경기 진행과 기록을 돕습니다. 나무위키와 제휴하거나 공식 지원을 받는 서비스가 아닙니다.
